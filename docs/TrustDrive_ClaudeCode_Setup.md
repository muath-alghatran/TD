## ثانياً: الأدوات — مرتّبة بالأولوية

### الطبقة الأولى · مدمجة في Claude Code (الأهم — لا تحتاج تحميل)

| الأداة | لماذا تهمك تحديداً |
|---|---|
| **CLAUDE.md** | يُحمَّل في كل جلسة. هنا تضع قواعد التصميم السبع حتى لا تكررها |
| **Hooks** | تنفّذ حتمياً بعكس التعليمات. اجعل `npm test` يعمل قبل كل توقف — فلا يمكن كسر محرك الوعد بصمت |
| **Subagents** | سياق منفصل. وكيل يدقق التصميم مقابل النموذج، وآخر يختبر محرك الوعد |
| **Plan Mode** | قبل كل مرحلة: اطلب الخطة أولاً، راجعها، ثم نفّذ. يوفّر ساعات إصلاح |
| **Checkpoints / Rewind** | تراجع فوري حين ينحرف البناء — أرخص من إصلاح يدوي |
| **`/clear`** | بين المهام. السياق الطويل يُضعف الدقة تدريجياً |

**هذه الطبقة تعطيك ٨٠٪ من القيمة.** لا تنشغل بـMCP قبل ضبطها.

### الطبقة الثانية · خوادم MCP

| الخادم | متى | الأمر |
|---|---|---|
| **قاعدة البيانات** (DBHub) | من المرحلة ٢ | `claude mcp add --transport stdio db -- npx -y @bytebase/dbhub --dsn "postgresql://readonly:pass@host:5432/db"` |
| **GitHub** | من المرحلة ١ | `claude mcp add --transport http github https://api.githubcopilot.com/mcp/ --header "Authorization: Bearer YOUR_PAT"` |
| **Sentry** | بعد الإطلاق | `claude mcp add --transport http sentry https://mcp.sentry.dev/mcp` ثم `/mcp` للدخول |
| **متصفح آلي** | من المرحلة ٤ | ابحث في [claude.ai/directory](https://claude.ai/directory) عن أداة أتمتة متصفح موثوقة |

**قاعدة أمان:** استخدم مستخدم قاعدة بيانات **للقراءة فقط** في DSN. لا تعطِ صلاحية كتابة لأداة آلية على بيانات طلبات حقيقية.

**تحذير:** تحقق من ثقتك بأي خادم قبل ربطه — الخوادم التي تجلب محتوى خارجياً تعرّضك لخطر حقن التعليمات.

**خادم المتصفح هو الأثمن لمشروعك:** يمكّنك من قول «افتح النموذج وافتح موقعي، والتقط الاثنين، وقارن الألوان والمسافات» — وهذا بالضبط ما يحفظ الانضباط البصري.

### للتطبيق مستقبلاً
نفس الإعداد يعمل بلا تغيير. المهم من الآن: **وثّق عقود الـAPI في `docs/api-contracts.md`** ليقرأها Claude Code حين تبني React Native بعد تسعة أشهر.

## ثالثاً: الملفات — انسخها كما هي

### `CLAUDE.md`

```markdown
# Trust Drive — سياق المشروع

## ما هو
منصة قطع غيار سعودية. الفكرة الجوهرية: لا نعرض "متوفر/غير متوفر" —
نعرض وعداً محسوباً بالثقة (أيام + نسبة) بثلاث حالات لونية.

## المراجع
- `docs/TrustDrive_Prototype.html` — المرجع البصري والسلوكي. الحقيقة النهائية.
- `docs/TrustDrive_Dev_Brief.md` — المواصفات ونظام التصميم
- `docs/TrustDrive_Build_Plan.md` — المراحل والبوابات
- `docs/TrustDrive_Parts_Master.xlsx` — بنية البيانات ومعادلة محرك الوعد

## قواعد لا تُكسر
1. اللون المشبع = حالة التوفر فقط. لا أزرار ملونة، لا تدرجات زخرفية، لا لون علامة.
2. الخطوط: Alexandria (عناوين) · IBM Plex Sans Arabic (نص) · IBM Plex Mono (أرقام).
3. الأرقام: بيانات الآلة لاتيني أحادي المسافة · سرد الإنسان عربي-هندي (٢٤ ساعة).
4. العتبات والإعدادات من جدول Setting في قاعدة البيانات — لا في الكود.
5. الحالة الرمادية لا تعرض تاريخاً. النص الوحيد: «نؤكد لك التوفر خلال ٢٤ ساعة».
6. الحالة الرمادية تحجز ولا تسحب (Authorization بلا Capture).
7. كل بحث فاشل وكل ضغطة "أبلغني عند التوفر" تُسجَّل في DemandGap — من اليوم الأول.
8. RTL أساسي · العربية اللغة الأولى.
9. prefers-reduced-motion يوقف كل حركة.
10. Fitment يربط بـ generationCode (XV70) لا بالسنة.

## الأوامر
npm run dev · npm run build · npm test · npx prisma studio

## أسلوب العمل
- خطة أولاً، ثم تنفيذ. توقف بعد كل مرحلة للمراجعة.
- اختبارات محرك الوعد تُكتب قبل الكود.
- لا تخترع ألواناً أو خطوطاً — استخرجها من النموذج.
- عند الشك في مظهر شيء: افتح docs/TrustDrive_Prototype.html واقرأه.
```

### `.claude/settings.json`

```json
{
  "permissions": {
    "allow": [
      "Bash(npm run:*)",
      "Bash(npm test:*)",
      "Bash(npx prisma:*)",
      "Bash(git status)",
      "Bash(git diff:*)"
    ],
    "deny": [
      "Bash(rm -rf:*)",
      "Read(./.env)",
      "Read(./.env.*)"
    ]
  },
  "hooks": {
    "PostToolUse": [{
      "matcher": "Edit|Write",
      "hooks": [{
        "type": "command",
        "command": "npx prettier --write \"$CLAUDE_FILE_PATHS\" 2>/dev/null || true"
      }]
    }],
    "Stop": [{
      "hooks": [{
        "type": "command",
        "command": "npm test --silent 2>&1 | tail -20"
      }]
    }]
  }
}
```

> **هذا الـ hook هو صمام الأمان الحقيقي.** الاختبارات تعمل قبل كل توقف، فلا يمكن كسر محرك الوعد دون أن تعرف فوراً.

أنت مدقق تصميم لمشروع Trust Drive.

اقرأ docs/TrustDrive_Prototype.html ثم افحص الكود المطلوب وتحقق من:

7. علامات التسجيل في زوايا الألواح

### `.claude/agents/promise-tester.md`

```markdown
---
name: promise-tester
description: يتحقق من مطابقة محرك الوعد للنموذج وورقة الإكسل. استخدمه بعد أي تعديل عليه.
---

تحقق من أن src/lib/promise-engine.ts يطابق دالة calc() في
docs/TrustDrive_Prototype.html وورقة 06 في الإكسل.

الحالات المرجعية الإلزامية:
- مخزون داخلي (stock>0) → الرياض   = 99% أخضر
- مندوب rel=.95 → أبها (t=.85)     = 81% أصفر، 6 أيام
- مورد rel=.62 → الرياض            = 62% رمادي
- مساعد rel=.95 → أبها + fit       = 95% أخضر، 3 أيام
- الحدود عند 0.85 و 0.65 بالضبط

تحقق أيضاً أن كل الثوابت تُقرأ من جدول Setting ولا شيء مكتوب في الكود.
```

## خامساً: الترتيب الصحيح للإعداد

1. أنشئ المشروع وانقل `docs/`
2. اكتب `CLAUDE.md` — **قبل أي كود**
3. أضف `.claude/settings.json` بالـ hooks
4. أضف الوكيلين
5. اربط GitHub MCP
6. ابدأ المرحلة ١
7. اربط قاعدة البيانات MCP في المرحلة ٢
8. اربط المتصفح في المرحلة ٤
9. اربط Sentry بعد الإطلاق

> **لا تربط كل شيء من البداية.** كل خادم يستهلك سياقاً، والسياق المزدحم يُضعف الدقة. أضف الأداة حين تحتاجها فعلاً.

## الخطأ الأكثر تكلفة

أن تظن أن الأدوات تعوّض عن البوابات. **لا تعوّض.**
Claude Code سريع لدرجة أنك تبني ست مراحل في يومين — والخلل يظهر بعد الإطلاق حين يكون إصلاحه أغلى عشر مرات.

الـ hooks والوكلاء في هذه الحزمة موجودون لسبب واحد: أن يجعلوا تجاوز البوابة **صعباً**.
