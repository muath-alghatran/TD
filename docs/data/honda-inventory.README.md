# مخزون هوندا — دليل تعبئة الملف

انسخ `honda-inventory.template.csv` باسم `honda-inventory.csv` في المجلد نفسه، واملأ صفاً لكل قطعة في مخزون المركز، ثم شغّل:

```
npm run catalog:honda
```

السكربت يتحقق من الملف ويولّد `src/lib/honda-inventory.ts`. قطعة بكمية أكبر من صفر تظهر **خضراء بدفع فوري** لسيارات العميل من الجيل نفسه، بسعرها من هذا الملف لا من قائمة الأسعار الاسترشادية (قاعدة 11). حل مؤقت: في المرحلة 7 ينتقل المخزون إلى قاعدة البيانات ويُعدَّل من لوحة التحكم بلا نشر جديد.

> **المستودع عام.** ضع في الملف سعر البيع للعميل والكمية فقط — وهما يظهران في الموقع أصلاً. **لا تضع سعر المورد ولا التكلفة** ولا أي عمود غير المذكور أدناه (السكربت يرفض الأعمدة الزائدة).

| العمود | المعنى | مثال |
|---|---|---|
| `generation_code` | رمز الجيل كما في `vehicle-catalog.csv` لهوندا | `CR` · `CV` · `RW` |
| `model` | اسم الموديل كما في الكتالوج | `أكورد` |
| `zone` | منطقة المخطط | `Z1` المحرك والتبريد · `Z2` البدي الأمامي والصدام · `Z3` الفرامل والعفشة الأمامية · `Z4` الكهرباء والبطارية · `Z5` المقصورة والتكييف · `Z6` العادم والوقود · `Z7` الفرامل والعفشة الخلفية · `Z8` البدي الخلفي والشنطة |
| `part_key` | نوع القطعة من `parts-glossary-seed.csv` | `front_pads` · `radiator` |
| `oem_number` | رقم القطعة | |
| `name_ar` | اسم القطعة كما يعرفه العميل | `قماش أمامي أكورد` |
| `quality_tier` | الجودة: وكالة · أصلي · ياباني · كوري · تايواني · تايلندي · ماليزي · تجاري | `وكالة` |
| `origin` | بلد المنشأ | `اليابان` |
| `price_sar` | سعر البيع للعميل شاملاً الضريبة (ريال) | `240` |
| `stock_qty` | الكمية في المخزون (عدد صحيح) | `3` |
| `warranty_months` | الضمان بالأشهر (فارغ = يُحدَّد عند التأكيد) | `12` |
| `labor_hours` | ساعات التركيب في المركز (فارغ = تُحدَّد عند التأكيد) | `1.5` |
