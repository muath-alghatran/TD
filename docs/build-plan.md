# الجزء الثاني · إعداد بيئة العمل

```bash
mkdir trustdrive && cd trustdrive
git init
npx create-next-app@latest . --typescript --tailwind --app --src-dir
mkdir -p docs
# انسخ الملفات الثلاثة إلى docs/
#   TrustDrive_Prototype.html
#   TrustDrive_Dev_Brief.md
#   TrustDrive_Parts_Master.xlsx
claude
```

### ملف `CLAUDE.md` في جذر المشروع

هذا أهم ملف في إعدادك — يقرأه Claude Code في كل جلسة تلقائياً، فيوفّر عليك إعادة الشرح:

```markdown
# Trust Drive — سياق المشروع

## ما هو
منصة قطع غيار سعودية. الفكرة الجوهرية: لا نعرض "متوفر/غير متوفر" —
نعرض وعداً محسوباً بالثقة (عدد أيام + نسبة ثقة) بثلاث حالات لونية.

## المراجع الملزمة
- `docs/TrustDrive_Prototype.html` — المرجع البصري والسلوكي. **الحقيقة النهائية.**
- `docs/TrustDrive_Dev_Brief.md` — المواصفات ونظام التصميم
- `docs/TrustDrive_Parts_Master.xlsx` — بنية البيانات ومعادلة محرك الوعد

## قواعد لا تُكسر
1. **اللون المشبع = حالة التوفر فقط.** لا أزرار ملونة، لا تدرجات زخرفية، لا لون علامة تجارية.
2. **الخطوط:** Alexandria (عناوين) · IBM Plex Sans Arabic (نص) · IBM Plex Mono (أرقام القطع والنسب).
3. **الأرقام:** بيانات الآلة بلاتيني أحادي المسافة · سرد الإنسان بعربي-هندي (٢٤ ساعة، ٣ أيام).
4. **العتبات والإعدادات تُقرأ من جدول Setting في قاعدة البيانات** — لا تُكتب في الكود أبداً.
5. **الحالة الرمادية لا تعرض تاريخاً محدداً** — النص الوحيد: «نؤكد لك التوفر خلال ٢٤ ساعة».
6. **الحالة الرمادية تحجز المبلغ ولا تسحبه** (Authorization بلا Capture).
7. **كل بحث فاشل يُسجَّل في DemandGap** — من اليوم الأول، بلا استثناء.
8. RTL أساسي · العربية اللغة الأولى.
9. `prefers-reduced-motion` يوقف كل حركة.

## الأوامر
- `npm run dev` · `npm run build` · `npx prisma studio` · `npm test`

## أسلوب العمل
- بعد كل مرحلة: أوقف واعرض ما بنيت للمراجعة قبل الانتقال.
- لا تخترع ألواناً أو خطوطاً — استخرجها من النموذج.
- اكتب اختبارات لمحرك الوعد قبل كتابته.
```

```

## المرحلة 2 · قاعدة البيانات ومحرك الوعد *(٣ أيام)*

```
أنشئ مخطط Prisma من قسم "نموذج البيانات" في docs/TrustDrive_Dev_Brief.md.
انتبه: جدول Fitment يربط بـ generationCode (رمز الجيل) وليس بالسنة.

نفّذ محرك الوعد في src/lib/promise-engine.ts كوحدة نقية مستقلة،
مطابقاً تماماً لدالة calc() في النموذج ولورقة 06 في الإكسل.
كل الثوابت تُقرأ من جدول Setting.

اكتب اختبارات vitest أولاً تغطي:
- مخزون داخلي → حائل (متوقع: 99%، أخضر)
- مندوب موثوق → أبها (متوقع: 81%، أصفر)
- مورد ضعيف → حائل (متوقع: 62%، رمادي)
- نفس القطعة مع mode=fit (الثقة ترتفع، مخاطرة الشحن تُلغى)
- الحدود الحرجة عند 0.85 و 0.65 بالضبط

ثم أنشئ سكربت seed يعبّئ البيانات التجريبية من النموذج.
```

**🚦 البوابة:** `npm test` كلها خضراء، والنتائج تطابق أرقام النموذج رقماً برقم. **هذه أهم بوابة في المشروع** — محرك الوعد هو المنتج.

## المرحلة 3 · الاستمارة وبطاقة التأكيد *(٤ أيام)*

```
ابنِ تدفق تعريف المركبة كما في النموذج (الشاشتان 01 و 02):

1. رفع/تصوير الاستمارة → OCR → استخراج: الصانع، الطراز، سنة الصنع،
   رقم الهيكل، رقم اللوحة.
2. من رقم الهيكل: فك محلي لأول 3 خانات (WMI) والخانة العاشرة (السنة)
   من جدول نملكه، ثم NHTSA vPIC كمساعد للمحرك والفئة مع تخزين دائم للنتيجة.
3. بطاقة تأكيد بدرجات ثقة لكل حقل: العالي مؤكد بعلامة صح،
   والمنخفض مبرَز بالأصفر مع زر تصحيح — مطابق للنموذج.
4. بعد التأكيد تُحفظ المركبة في "كراجي" ولا يُسأل عنها مجدداً.

إلزامي: مسار احتياطي يدوي كامل (ماركة/موديل/سنة) يعمل إن فشل كل ما سبق.
لا تدع المستخدم يعلق أبداً.
```

**🚦 البوابة:** جرّب **عشرين استمارة حقيقية** من سيارات عملائك في المركز. كم واحدة قُرئت صحيحة؟ إن كانت أقل من ١٥ — حسّن المعالجة قبل المتابعة، أو اجعل التصحيح اليدوي أبرز.

## المرحلة 4 · المخططان *(٥ أيام — الأصعب)*

```
ابنِ المخطط ذا المستويين كما في النموذج (الشاشتان 03 و 04):

المستوى الأول: مخطط SVG جانبي، 8 مناطق تفاعلية.
- كل عقدة ملوّنة بحالة توفرها
- أسفل كل عقدة نسبة التغطية "12/34"

المستوى الثاني: مخطط متفكك للمنطقة.

- أشكال القطع مرسومة بالخط (انسخ دالة glyph من النموذج)

بيانات المناطق والإحداثيات من ورقة 11 في ملف الإكسل.
كل ضغطة على "أبلغني عند التوفر" تُسجَّل في DemandGap فوراً.

**🚦 البوابة:** التنقل بالكيبورد يصل لكل عقدة بمؤشر تركيز ظاهر · قارئ الشاشة ينطق اسم المنطقة وحالتها وتغطيتها · المخطط مفهوم على شاشة جوال ٣٧٥ بكسل.

## المرحلة 5 · الاستلام والوعد والدفع *(٤ أيام)*

```
ابنِ الشاشات 05 و 06 من النموذج:
- اختيار المدينة يعيد الحساب فورياً بلا إعادة تحميل
- خيار التركيب: خصم 10% على أجرة اليد فقط (لا على سعر القطعة)
- بطاقة الوعد مع المقياس الدائري المتحرك وعدّاد النسبة
- تفصيل الحساب سطراً سطراً

الدفع عبر Moyasar:
- أخضر/أصفر → Capture كامل
- رمادي → Authorization فقط، بلا Capture
- مهمة مجدولة تفك الحجز تلقائياً بعد 24 ساعة إن لم يُؤكَّد التوفر

أعِد التحقق من السعر في الخادم قبل الدفع — لا تثق بأي سعر قادم من المتصفح.
سجّل مع كل طلب: promisedDays و confidenceAtOrder.
```

**🚦 البوابة:** اختبر بحالتين حقيقيتين ببطاقة فعلية — واحدة خضراء تُسحب، وواحدة رمادية **تُحجز ولا تُسحب**. تحقق من كشف الحساب بنفسك. لا تعتمد على رسالة نجاح في الشاشة.

# الجزء الخامس · بعد الإطلاق

1. نسبة الالتزام بالوعد

التوسع يقوده الطلب المفقود لا التخمين. أضف ماركة كل شهرين.

# نصائح تشغيل Claude Code

| المبدأ | التطبيق |
|---|---|
| **جلسة لكل مرحلة** | ابدأ جلسة نظيفة لكل مرحلة — السياق الطويل يُضعف الدقة |
| **`/clear` بين المهام** | داخل المرحلة الواحدة عند الانتقال لمهمة مختلفة |
| **الاختبار قبل الكود** | خاصة محرك الوعد — اطلب الاختبارات أولاً دائماً |
| **commit بعد كل بوابة** | نقاط تراجع آمنة، ورسائل واضحة |
| **صحّح فوراً** | إن انحرف عن النموذج، أوقفه في حينه — لا تدع الانحراف يتراكم |
| **اعرض النموذج** | حين يخطئ بصرياً، أشِر إلى النموذج بدل الشرح بالكلام |

**الخطأ الأكثر تكلفة:** أن تدع Claude Code يبني ست مراحل متتالية دون فحص. الكود سيبدو سليماً، والخلل سيظهر بعد الإطلاق حين يكون إصلاحه أغلى عشر مرات.

# تحذيرات أخيرة

- **ابدأ بوعود متحفّظة.** قل ٤ أيام وسلّم في ٣. الوعد المخلَف مرتين ينهي سمعة لا يصلحها تسويق.
- **دقة التوافق قبل حجم الكتالوج.** ٢٠٠ قطعة صحيحة أفضل من ٢٠٠٠ فيها ٥٠ خطأ.
- **لا تنافس بالسعر.** نافس بالوعد والضمان والتركيب — وهي أشياء لا يملكها متجر بلا ورشة.
- **الفجوة النقدية هي القاتل الصامت.** تدفع للمناديب كاش وتحصّل من الشحن متأخراً. جهّز رأس مال تشغيلي كافياً.
- **قبل لقاء الأساتذة:** اذهب بالنموذج مفتوحاً على جوالك ومعه بيانات ٥٠ طلباً حقيقياً. خمسون طلباً حقيقياً أقنع من خمسين شريحة عرض.

بالتوفيق. المشروع مبني على فكرة صحيحة — والتنفيذ المنضبط هو ما يحوّلها إلى شيء يستحق اسمك.
